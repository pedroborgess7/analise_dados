# 🎬 Análise de Dados de Filmes (IMDB)

## 📌 Sobre o Projeto

Análise exploratória de dados de filmes com foco em avaliação, faturamento, gênero e evolução ao longo dos anos.

O projeto cobre todo o pipeline de dados: desde a base bruta até a construção de um dashboard interativo.

---

## 📊 Fonte dos Dados

Dados obtidos da plataforma Kaggle, contendo informações como título, ano, gênero, avaliação e faturamento.

---

## 🛠️ Ferramentas

* SQL
* Excel
* Power BI
* Power Query

---

## 🔄 Pipeline do Projeto


Dados brutos → Limpeza e tratamento → Consultas SQL → Dashboard no Power BI

---

## 🧹 Tratamento dos Dados

* Remoção de colunas irrelevantes
* Tratamento de valores nulos
* Padronização de tipos de dados
* Separação de múltiplos gêneros em linhas
* Remoção de duplicidades

---

## 🧠 Consultas SQL

Foram criadas queries para apoiar a análise:

* Top 10 filmes mais bem avaliados
* Top 10 filmes com maior faturamento
* Quantidade de filmes por gênero

---

## 📊 Dashboard

O dashboard inclui:

* 🎬 Top 10 filmes por avaliação
* 💰 Top 10 por faturamento
* 📈 Filmes por ano
* 🎭 Filmes por gênero

---

## 🧠 Insights

* Drama é o gênero mais frequente
* Ação e aventura lideram o faturamento
* Produção de filmes cresce após os anos 2000
* Alta avaliação ≠ alto faturamento

---

## 🚀 Conclusão

O projeto demonstra o processo completo de análise de dados, desde a preparação até a geração de insights, utilizando ferramentas amplamente usadas no mercado.
